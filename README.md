# Project Overview

This repository contains files and resources for the EV Beetle project.

## Folder Structure

- `Display/`  
  DWIN display project files and resources

- `STM32 Workspace/`  
  The main STM32 development workspace, for the front and rear STM32s

- `Design.docx`  
  A Word document containing system design and planning notes.
